# On-the-fly: An Efficient Online Tucker Decomposition for Tensor Streams

The software and data in this repository are a snapshot of the code and data used in the research reported in the paper "On-the-fly: An Efficient Online Tucker Decomposition for Tensor Streams" by H. Xiao, K. Zhao, and A. Rai.

# Description
This repository contains the MATLAB implementation of tensor decomposition and baseline methods, including conventional Tucker decomposition, matrix factorizations, and neural-network-based autoencoder approaches.

The experiments compared the proposed OTD with these baselines on both synthetic and benchmark datasets, including the Columbia Object Image Library (COIL) datasets (main paper) and MNIST and CIFAR-10 datasets (online supplement).
