# Data

This directory contains the Columbia Object Image Library (COIL) datasets: PCOIL-20 and UCOIL-5, and MNIST and CIFAR-10 datasets.

# Included Datasets
- COIL/: both PCOIL and UCOIL images.
- MINST/: MINST images.
- CIFAR/: CIFAR-10 images.
